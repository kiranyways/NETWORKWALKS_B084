## Overview

This repository contains the practical tasks completed during Week 3 of the Networkwalks Cybersecurity Internship. The activities focus on recovering passwords from a protected PDF file using two different approaches: John the Ripper (JTR) and Networkwalks online password-cracking tools.

---

## Project Module 1: PDF Password Recovery Using John the Ripper

### Objective
To recover the password of a protected PDF file using John the Ripper and its graphical interface, Johnny.

### Steps Performed

1. Extracted the password hash from the locked PDF using an online PDF hash extraction tool.
2. Saved the extracted hash in a file named `hash1.txt`.
3. Opened Johnny (John the Ripper GUI).
4. Imported the `hash1.txt` file and configured the John the Ripper installation path.
5. Started the password-cracking process.
6. Successfully recovered the PDF password: `good-luck`.
7. Verified the recovered password by opening the protected PDF.

## Project Module 2: PDF Password Recovery Using Networkwalks Tools

### Objective
To recover the password of the same protected PDF using the Networkwalks Hash Calculator and Password Cracker.

### Steps Performed

1. Uploaded the protected PDF file to the Networkwalks Hash Calculator.
2. Generated and copied the PDF password hash.
3. Opened the Networkwalks Password Cracker.
4. Entered the extracted hash into the password-cracking tool.
5. Performed a dictionary-based password attack.
6. Successfully recovered the PDF password: `password1`.
7. Verified the result by opening the protected PDF using the recovered password.

## Learning Outcomes

During these practical activities, I learned:

- How to extract password hashes from protected PDF files.
- How to use John the Ripper and Johnny for password recovery.
- How to generate PDF hashes using online tools.
- How dictionary-based password attacks work.
